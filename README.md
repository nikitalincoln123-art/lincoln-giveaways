# Lincoln — витрина розыгрышей

Одностраничная витрина розыгрышей Telegram-канала [@AdapterLincoln](https://t.me/AdapterLincoln).

- 5 карточек розыгрышей с линейными иконками и ghost-номерами; таймеры обнулены (`00:00:00:00`)
- красный статус «Не проходит на данный момент» на каждой карточке
- архив победителей по каждому розыгрышу
- условия участия и контакт автора
- OG-превью и кнопка «Поделиться»
- мобильное меню и плавный скролл
- scrollspy, прогресс прокрутки, scroll-reveal, триллинг-строка, спотлайт за курсором, кнопка «Наверх»
- анимированный фон с никами `LincolnWasted`, туман, зерно, параллакс плиты
- 3D-плита Lincoln на чистом CSS
- JSON-LD, `robots.txt`, `sitemap.xml`
- без бэкенда, сборок и внешних зависимостей

## Локальный запуск

Откройте `index.html` в браузере — всё работает офлайн.

## Публикация

GitHub Pages: https://nikitalincoln123-art.github.io/lincoln-giveaways/

## Настройка

Список розыгрышей задаётся массивом `draws` в `index.html`, тексты шагов — в секции `#how`.

Победители добавляются в массив `winners` нужного розыгрыша:

```js
winners: [
  { name: "@username", prize: "10 мишек" }
]
```

Превью для соцсетей — файл `og-cover.png` (1200×630).
